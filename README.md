# 澳洲高级贷款计算器

符合澳洲本地市场的图形化贷款计算器，支持特殊需求定制。

## 功能特点

✅ **标准贷款计算** - 计算月供、总利息、总还款  
✅ **印花税计算** - 包含澳洲全部州最新税率表  
✅ **House & Land 支持** - 勾选后仅对土地价格计算印花税  
✅ **可自定义费用**  
  - 律师费可改（默认按州预置）
  - PEXA 交割费可改（默认市场均价）
  - LMI 保险（可选）
  - 其他费用（可选）
✅ **交割缺口计算** - 根据客户现金计算最终交割还需要多少钱  
✅ **图形界面** - 原生 Tkinter，macOS 直接运行不需要额外依赖  

## 运行方式

### 方式一：命令行直接运行

```bash
cd /path/to/loan-calculator
python3 loan_calculator.py
```

### 方式二：打包成 macOS App

运行提供的打包脚本：

```bash
chmod +x create_app.sh
./create_app.sh
```

会生成 `LoanCalculator.app`，可以直接双击在 macOS 启动。

## 使用说明

1. **房产信息**
   - 填写总房价
   - 选州，自动切默认律师费
   - 如果是 House & Land 项目，勾选 "House & Land" 然后填写土地价格

2. **贷款信息**
   - 输入你获批的贷款金额、年利率、贷款年限

3. **费用信息**
   默认值已经填了市场平均价，可以改成你实际的数字
   - 律师费：过户律师收费
   - PEXA：PEXA 电子交割费
   - LMI：贷方抵押保险，如果贷款比例超过80%一般会有
   - 其他费用：政府登记费、经纪费等等

4. **客户资金**
   输入客户手头有的现金/存款，计算器会自动算出来交割缺口：
   ```
   缺口 = (房价 + 所有费用 - 贷款) - 客户现金
   ```
   - 正数 → 还要准备这么多现金
   - 负数 → 交割后还剩钱
